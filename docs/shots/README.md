## 讲的时候值得强调的三条

1. **能力和护栏是同一套结构长出来的**，不是嘱咐它别做。定稿改不动是因为没 grant；
   发不出信是因为 `send` 不在工具白名单；越不过线是因为每个写口第一个参数都是 `pursuit_id`。
   见 `brain/README.md`。
2. **绝不丢信息**：位置也是信息（URL 记着你在哪）、负面结果也是信息（查了没建卡的写进战报）、
   过期判断也是信息（卡里留着「2026-08-15 修正记录」而不是悄悄改掉）。
3. **它做功课，你做决定**。每一处「它能自动做完」的地方都停在你面前一步：读透了等你批、
   收进产出去那儿改完再发、确认发给某某要按两下。

## 打码（2026-08-17 重截）

图里所有第三方真人姓名换成了占位标签，邮箱一律 `[email]`。同一个人在**两套图的所有图里是同一个标签**，
所以讲的时候还能指认「就是这个人」，只是不知道他是谁：

| 标签 | 是谁 |
|---|---|
| `[Contact A]` / `[Contact B]` / … | 往来里的联系人（机构对接人、策展人…） |
| `[Prof. A]` / `[Prof. B]` | 那条博士线上的两位教授 |
| `[Faculty C]`–`[Faculty K]` | 同系的其他教员 |
| `[Peer A]` / `[Peer B]` / `[Peer C]` | 圈内同行 / 引荐人 |
| `[Student A]` / `[Student B]` | 学生 |
| `[Person 1]`… | 通讯录里其余的人（按出现顺序自动编号） |
| `[Org R]` | CultureHub —— 驻地名单还没公开，机构身份连同 `culturehub.org`、创办方一起挡了 |
| `[email]` | 任何邮箱地址 |

**没挡的**：机构名（Theodore Payne Foundation、SFCB 这类，不是个人信息）、你自己的名字和作品名。
你自己的名字要不要一起挡，说一声我再跑一遍。

打码跟英文版一样是截图时在浏览器里做的**临时覆盖**，库里一个字没改。
