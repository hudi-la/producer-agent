# 手回到 Gmail：发信不再有第二个现场（2026-08-26）

## 一句话

系统只做三件可信的事——**写字、带路、递纸**。挂哪串、发给谁、发不发，
全部由你的手在真 Gmail 里按出来。发出之后同步抓到事实，自动记账、关门。

## 判据（这稿所有取舍的唯一来源）

- 信任的来源不是「看到的结果」，是「**动作在正典工具里由我做出**」。
  实例：合作者说「我拉了个负责人进来，请你 Reply All」——你不知道
  Reply All 发出来长什么样，照点。因为动作是 Gmail 的，不需要被理解
  就可以被信任。
- 任何复制品——预览、信封页、API 替你建的草稿——都要求你信一个
  **看不见的决定**（它挂对串了吗？名单全吗？）。信任问题原样递归，
  做得再忠实也一样。
- 账本是抄本。发信的决策不许建立在抄本上。**事后的观察**（全局同步
  抓到已发出的信）才可靠，因为它读的是已经发生的事实。

## 形态

右栏退出发信。中间栏对话里的信卡（带信封那种）上，两颗按钮：

1. **「去 Gmail 打开这串 ↗」**——纯导航，深链
   `https://mail.google.com/mail/u/0/#all/<threadId>`；浏览器同时登着
   几个 Google 账号时会错箱，所以带上 `authuser=`（profile 里那个邮箱）。
   带错路会**自曝**：你人已经站在真线程里，一眼看出「这不是那串」——
   导航错误不需要防，看见就是防。这条线没认领过串（新起的信）→
   这颗不显示。
2. **「复制这封信」**——正文进剪贴板，`text/html` + `text/plain` 双份，
   HTML 用跟页面**同一套** remark 栈渲（Md.jsx 那次「粗体变四个星号」
   的事故不许再演一遍）：屏幕什么样，贴进 Gmail 什么样。新起的信
   主题单独一行小字，旁边自己的复制点。

然后你的手接管：在该回的那封信上按 Reply 还是 Reply All——名单
Gmail 算；粘贴；按 Gmail 的发送键。

之后是已经设计好的下半场：全局同步抓到这封去信 → 入账（`pa_add_mail`
拿 `gmail_message_id` 去重）→ 走 `MY_LETTER` 判断 → 这条线上手动记的
「要写信」提醒自动关掉，新的等待照 0819 稿开出来。**开门手动、关门
自动**——这是「自己发起的事进提醒」那场讨论定下的接口，本稿是它的
关门信号来源。

## 死掉的东西

- 「收进产出」和 `kind='email'` 的产出卡：邮件不再进右栏。
- 信封页、忠实预览、「放进 Gmail 草稿箱」（API 建草稿挂串）：全否，
  理由见判据。
- 附件退路：不需要专门留了——你本来就在 Gmail 里，直接加。

## 留着不动的

- brain 的 `POST /mail/send` 直发管道：**代码不拆**，UI 入口撤。
  哪天出现「毫无歧义的信」（新信、单收件人、无串）想一键直发，再议。
- 右栏本身和非邮件产出（bio 等）的去留：另一稿的事。本稿只把邮件撤走。
- 8/18 修出来的 `pa_reply_recipients`（从信头算全名单）：不再是发信
  界面的地基，但留着——判断和展示层还用得上。

## 怎么验收

1. 在一条认领过串的线上让 Fairwind 写一封回信 → 信卡上出现
   「去 Gmail 打开这串 ↗」和「复制这封信」。
2. 点带路 → 浏览器落在 Gmail 里正确的那条会话（多账号登录下也对）。
3. 点复制，在 Gmail 里按 Reply All 粘贴 → 粗体是粗体，列表是列表。
4. 从 Gmail 发出后跑一次同步 → 左栏往来多一条「你」；这条线上若有
   手动记的「要写信」，那条提醒自动消失。
5. 新起的信（无串）→ 只有复制没有带路；主题可单独复制。

## 走过的弯路（记下来防重走）

这稿之前按顺序否掉了四个方案，全部倒在同一条判据上：

| 方案 | 倒在哪 |
|---|---|
| 系统内忠实预览 | 预览是复制品；决定还在暗处 |
| 信封页（现场拉 Gmail 原件当决定页） | 材料是真的，执行决定的还是仿品界面 |
| API 建草稿挂串 + 深链 | 挂哪串是代码替你做的暗决定 |
| 桌面壳（Electron/Tauri）停靠真 Gmail | 能成立，但打包/更新/登录态是一整套新债；复制粘贴两下就能换来同等信任，不值 |

判据一次说死：**凡要求「相信一个看不见的决定」的形态，都不过关。**
另有一条硬事实别再试：浏览器网页 iframe 嵌 mail.google.com 被
`X-Frame-Options: DENY` 焊死，没有正路可绕。
