# 语气是数据 —— 第二层落地

2026-08-24

## 为什么

今天一个艺术家想改 Fairwind「是谁、信怎么写、该拒绝什么」，只有一条路：改
`brain/prompt.js` 里的常量字符串。这是最该属于他自己的东西，却是唯一必须
懂 JavaScript 才能碰的东西。

这一刀把它变成数据。

## 三层（定义按「改的是什么」，不是「怎么改」）

| 层 | 是什么 | 住在哪 |
|---|---|---|
| 一 · 数据 | 他的档案、作品、人、机会、盒子 | 数据库。靠**用**来定制，已经通了 |
| 二 · 语气和判据 | 它是谁、信怎么写、什么该拒绝 | **今天是 JS 常量。这一刀搬进数据库** |
| 三 · 能力 | 新信号、新集成、新的列、状态机判据 | 源码 |

**进第三层有四条路，vibecoding 只是其中一条**，而且不是默认那条：

1. **作者发新版本** —— 十个人里六个想要同一个东西，那不是定制，是缺功能。
   这该是最常见的那条路。
2. **写好的模块让人开关** —— 看着像配置，实际是第三层。
3. **vibecoding** —— 能且愿意的少数。
4. **花钱找人做**。

### 二三层之间是棘轮，不是墙

边界是**可以移动的设计选择**，而且只往一个方向动：每当一个第三层的需求被
证明是很多人共有的，它就该被**降级**成第二层。哪些该降，workshop 是测量仪器。

**这个向下移动本身就是产品化。** 不需要某一天宣布「开始做产品」，只需要在
拿到一期学员的数据后，看哪几样该往下掉。

### 第三层里两处挂「别动」牌子的地方

- **`brain/judge.js` 的 `TRANSITIONS`** —— 改错一格是**静默瘸腿**：不报错，
  只是再也不提醒你回信。非程序员没法修一个不会报错的故障。
- **`server.js` 的 `READ_TOOLS` / `GMAIL_TOOLS` 白名单** —— 那两个常量**本身
  就是护栏**。删掉一行，一个握着 service_role key 的 agent 就拿到了整台机器的
  Bash。

这两处**不搬进第二层**，永远留在源码里。用户改不了判据，但也炸不了。

## 做什么

### 五个格子

`producer.voice` 单例表（多租户那刀改成每人一行），五个可空的文本格子。
**空 = 用代码里的原文**。

| 格子 | 覆盖的是 | 今天在哪 |
|---|---|---|
| `agent_name` | agent 叫什么（**Fairwind 是产品名，每人给自己的随便起**，2026-08-24 他拍板） | `prompt.js` 写死「 Fairwind 」 |
| `persona` | 「你的活 + 怎么做事 + 你不能做的」那段行为描述 | `prompt.js` `systemFor()` |
| `letter_rule` | 写信的规矩 | `prompt.js` `LETTER_RULE` |
| `form_rule` | 填表的规矩 | `prompt.js` `FORM_RULE` |
| `judge_rule` | 判断时的那段小人格 | `server.js` + `replay.js`（**现在抄了两份**） |

**「你服务的艺术家是 X，作品站 Y」那句不做成格子** —— 它是第一层的数据，
从 `profile` 现算，本来就已经是数据了。

顺带修掉 `judge_rule` 那份两处复制：默认值统一 export 自 `prompt.js`。

### 安全性质：空表 = 一个字都不差

这是整刀的判据。`voice` 表是空的时候，拼出来的 prompt 必须跟今天**逐字相同**。

理由不只是谨慎：`prompt.test.js` 那把「老实现逐字复刻」的尺子还在，静态块
一个字都不能飘，否则跨会话缓存全废。所以覆盖是**逐格生效**的——只填了
`letter_rule`，其余三格照旧走代码原文。

### 走哪条路进 brain

不加新的网络往返：`pa_brain_context` / `pa_brain_person_context` 这两个 RPC
本来每次开工就调，把 `voice` 挂进它们返回的那包里即可。

### 导出

`v_pa_voice` 视图直接可读，就是导出。学员愿意的话可以把这四格给作者看——
**十个人各自把它调成了什么样，就是产品该做成可配置的地方**。信件和往来是
他们的，不在这里面。

## 不做

- **多租户**。这是重写级别，而且形态应该是「每人一个自己的库」，不是一个库
  装十个人。
- **`TRANSITIONS` 搬进库**。见上面「别动」。
- **UI**。这一刀只做通路和 brain 读取；档案页那几个 textarea 是下一刀，
  照 `Identity.jsx` 的样子抄。
