# 工作区：桌面和架子（2026-09-02）

> 界面上这个区叫「**展开的卡片**」（2026-09-03 他定的），抽屉头上那颗叫
> 「展开 / 在展开的卡片区 →」，卡角记号叫「在展开的卡片区」。稿子里下面仍写
> 「工作区」，指的是同一个东西。
>
> 2026-09-03 又改了两处（同一天，他用出来的）：
> 1. **第二下不再是拿走，是「带我去那一格」。** 拿走只有一个出口：那排卡片上的 ×。
>    一颗按钮既能放进去又能拿走，看着一样、按下去两个结果，你得先想它现在是哪面。
> 2. **有小红点的线自己摆进那一排**（lib/desk.js 的 autoOpen）。红点说的是
>    「Fairwind 说了话你还没读到」——那正是今天该弄的，不该等你去看板上一列列找。
>    读了红点自己灭；按 × 关掉的这一轮不会再自己回来（它不认这句话就成了赶不走的东西）。
>    那一排里未读的格子带一颗红点，跟看板上那颗是同一个意思。
> 3. 点「展开」时一个带卡名的小标签飞到顶栏那个字上、落地弹一下（lib/fly.js）——
>    跟购物车一样。动画不承载事实：三处状态照旧当场翻面，关了动效直接弹一下。

## 一句话

一级导航头一个加「工作区」——今天摊在桌上的活。后面四个（项目争取、
人际管理、我的档案、时间线）是架子：东西住在那儿，你去找到一个，
拿到桌上来做。二级那条带子只在工作区底下有，装的是开着的窗口，
线和人混排，带 ×，用完关掉。过卡队列并进来，就是这排窗口。

## 判据（这稿所有取舍的唯一来源）

- **不做要教才会用的界面。** 一个没见过 Fairwind 的人，看一眼就得知道
  第二排和第一排是什么关系。「底下」这个位置自带从属的意思——放在
  「项目争取」底下的一排，任何人都会当成项目争取里面的分栏，可它偏偏
  混着人。所以第二排只许出现在它真正属于的那个字底下。
- **动作发生的那一刻，看得见东西去了哪。** 「放到工作区」留在原地不跳，
  跟「加入购物车」一个道理：不是靠跳过去证明发生了，是靠三处状态当场
  翻面（按钮、顶栏数字、看板上那张卡的记号）。
- **不要让他对账。** 「手头这摊活」只许有一份。过卡队列和打开的窗口形状
  一模一样（混着线和人、存本地、能移出），两个并存就会出现「在队里但
  没开窗」「开着窗但不在队里」——合成一个。
- **没在用的东西撤，不留位。** 待处理/紧急、人/机构、日历/流水三组视图
  切换，实际都不用。撤掉，二级带子才腾得出来只讲一件事。

## 形态

### 顶栏

```
Fairwind   工作区 · 4   项目争取   人际管理   我的档案   时间线      邮件：3 分钟前收过  🔔  我
```

- 「工作区」排第一。后面挂个数：桌上几张。空着不挂数。
- 铃铛和收信状态从二级带子搬上顶栏右端，跟你的名字一排。它们是全局的
  东西，本来就不该住在某个区的带子里。
- 点任何一级按钮 = 去那个区的首页；工作区里正看着的那张不关，回来还在。

### 工作区底下那一排

```
 Kunstverein 申请 ×   Maria Chen ×   ZKM ×   Descanso Gardens ×
```

- 只在「工作区」亮着的时候出现。别的区底下**没有第二排**。
- 一张一个格：线的名字 / 人的名字 / 机构名。线和人混排，按放进来的
  先后。当前那张亮。
- 点一格 = 整页摊开（PursuitFocus 的 page 形态、PersonFocus、OrgFocus）。
- × = 关掉，就是原来的「移出」：这张从桌上拿走，卡里什么都不碰。关掉
  当前那张就切到旁边一张，没有了就显示空桌。
- 一天少则两三张，多则六七张，一排放得下。放不下时横向滚，格子不许
  缩到看不见名字——看不见题目等于没开。
- 空桌就一句话：「桌上没东西。去看板或通讯录挑，抽屉头上按「放到工作区」。」
  不做主页，不做早报。

### 从架子拿到桌上

看板点卡片、通讯录点人 / 机构，**都先出抽屉**，看一眼就走，底下的看板 /
列表不动。（通讯录现在是原地换页，改成跟看板一样出抽屉——线和人两套
规矩就得教，不许。）

抽屉头上原来的「整页」换成一颗开关：

- 没在桌上：显示「放到工作区」。按下去三处当场变：这颗翻成「在工作区 ✓」；
  顶栏「工作区」后面的数字加一；看板 / 列表上那张卡角上出个小记号。
  **人留在原地**，接着挑下一张。
- 已在桌上：显示「在工作区 ✓」。再按一下拿回来，三处一起复原。

挑完了自己点顶栏「工作区」过去。

### 过卡队列并进来

`lib/queue.js` 那份本地存档就是桌子——items 里 `{kind, id, via}` 正是一格
窗口，机构也能上桌（kind='org'）。「批量操作 → 过一遍」= 勾的几张一起放上桌，
**然后过去**（这颗按钮说的就是「开始过这一摞」，不是挑）；「移出」= ×。
卡头里那条 ‹ 3/12 › 移出 的过卡条撤掉：那一排窗口就是导航，两份导航要教。
原来二级带子上「过卡 · N」那颗按钮撤掉，数字挂在顶栏「工作区」上。

### 动作按钮跟着它作用的东西走

- 看板头一行：「批量操作」「造卡任务」。勾选时那一行换成
  「说一句…」「过一遍」「取消」，跟现在一样，只是位置从带子进了看板。
- 通讯录列表顶上：「＋ 新联系人」「批量操作」。新联系人照旧弹浮层。
- 时间线：日历 / 流水那两个切换搬进时间线页自己的头上（内容里，不是导航）。
  两半都还看得见——撤掉切换让日历不可见，就是丢信息。等调好了再合成一页。

### 地址栏和刷新

- 桌子存本地（`pa_queue` 那份，不上库），刷新不丢。
- 地址栏照旧写当前那一张（?p= / ?c= / ?o=）。进来时按地址恢复：那一张
  若不在桌上，自动放上桌再打开——地址是你带来的，不许弹回首页。
- 标签页名字：工作区里看哪张就叫哪张的名字（跟现在整页一样）。

## 死掉的东西

- 二级带子上的三组视图切换：待处理 / 紧急、全部 / 人 / 机构（日历 / 流水
  搬进时间线页里）。`lib/filters.js` 的镜头逻辑连带撤掉。
- 「过卡 · N」按钮和「整页」按钮（都被「放到工作区」开关替代）。
- 「再等一等」和停手面板（QueueRest）：窗口开着不动就是「先放着」，
  用不着一个专门的按钮来说这句话；「这轮你都看过了」这个事实排在眼前，
  不用一块面板来讲。队列里 skipped / skippedAt 两个字段跟着退役。
- 卡头里的过卡条（QueueNav）：‹ › 和「移出」都在那排窗口上了。
- 人际管理里名片、机构的「原地换页」和 ⌘/Ctrl 点新开浏览器标签页：
  前者改成抽屉，后者保留给浏览器自己的规矩（地址栏还在，复制得走）。

## 留着不动的

- 抽屉本身：形态、拖宽、Esc 关都留。
- 通知面板、气泡视图、批量操作的勾选逻辑（picked 混线和人）。
- PursuitFocus / PersonFocus / OrgFocus 三个详情页的内容。
- 展示模式（小花）照旧盖标签名。

## 怎么验收

1. 冷启动落在看板。顶栏第一个是「工作区」，不挂数；底下没有第二排。
2. 看板点一张卡 → 抽屉出来，看板不动。抽屉头上是「放到工作区」。
3. 按它 → 按钮翻成「在工作区 ✓」，顶栏变「工作区 · 1」，看板上那张卡
   角上出记号。人还在看板。再按一下 → 三处复原。
4. 通讯录点一个人 → 也是抽屉，同样一颗开关。放上桌后顶栏变「· 2」。
5. 点顶栏「工作区」→ 底下一排两格（一条线、一个人），第一格亮，整页
   摊开。点第二格 → 切到名片。
6. 按 × 关当前那张 → 切到旁边那张；再关 → 空桌那句话。
7. 放三张上桌，刷新 → 三张都在，正看着的那张还是那张。
8. 批量操作勾四张 → 过一遍 → 顶栏 · 4，工作区里四格。
9. 别的区底下没有任何第二排；铃铛在顶栏右端，收信状态在它左边。

## 走过的弯路（记下来防重走）

| 方案 | 倒在哪 |
|---|---|
| 二级带子直接改成开着的标签（各区共用） | 位置在项目争取底下，读起来就是它的分栏，可它混着人 |
| 并进顶栏同一排（四个区不带 ×，后面接带 × 的） | 六七张一排顶不开，看不见题目 |
| 一级加工作区，「放到工作区」立刻跳过去 | 挑六七张要来回跳六七次；留在原地靠三处翻面已经说清了去哪 |
| 左边竖栏放区、横排放窗口（VSCode 骨架） | 读得通，但整个骨架要换，看板本来横向铺开会更挤；不值 |

「工作区内容多、别的区内容少」看着不平衡——不是问题。桌子满、架子安静，
本来就是两种东西。
