# 你的判据

这个文件夹里的 `.md` 文件，是你告诉 Fairwind「这类事我怎么看」的地方。
它每判一封信、一笔手记，都会把对应文件里的话读一遍。

| 文件 | 什么时候用 |
|---|---|
| `全部.md` | 每一次判断都带上 |
| `对方来信.md` | 对方发来一封信 |
| `我发出的信.md` | 你发出一封信 |
| `手记.md` | 你自己记了一笔（见了面、打了电话、交了表） |
| `见面之后.md` | 见完面 Fairwind 问你「见得怎么样」，你回答的那一句 |

没有的文件就是没有。空着也行。

## 怎么写

像跟一个熟悉这行的助手交代一样写，几句话就够：

```
投递、申请、提案这类，我等 30 天再问，不急。
约时间、要材料的，5 天没回就提醒我。
拿不准要不要回的，宁可提醒我，别自己压下去。
约了见面时间的，见面优先——哪怕对方还欠我一个链接。
```

改完**不用重启**，下一次判断就用新的。

## 写了也不生效的

Fairwind 每次判断返回哪几个字段（要不要回、等多久、约了什么时候、一句话梗概）是固定的。
文件里写「加一个字段」「删掉 gist」这类话，它会在启动时告诉你这句没用，然后照常跑。

## 试试看

在页面「我的档案 → 关于你」底下有「看看会怎么变」：拿你最近判过的二十件事，用现在的判据再判一遍，
把原来的结论和现在的结论并排给你看。改数字是抽象的，看见「这封原来提醒我 8/14 催、现在 8/24」是具体的。

## 出了问题

同一处有「用我的判据 / 用出厂判据」的开关。关掉就是出厂的。
Fairwind 判不出来的时候（没按格式回话）会自动用出厂判据再判一次，并在日志里说是哪个文件惹的。
